Instance URL Suffix

Controls how wiki instance URLs are formed. By default, all instances (including admin-created ones) use the suffix: mywiki-hosting.domain.com. Admin accounts can override this per-instance by choosing apex mode at creation time.

Default: hosting → mywiki-hosting.domain.com. Change to any word (e.g. wiki → mywiki-wiki.domain.com). Only affects new instances.

Expired Wiki Owner Permissions

Control what wiki owners can do once their trial has expired. Both options are disabled by default, only admins can act on expired wikis unless you enable them here.

When enabled, wiki owners can terminate and delete their own expired (but not yet cleaned-up) wikis without contacting an administrator.

When enabled, wiki owners can download a ZIP archive of their terminated wiki's data during the grace period. Has no effect when the grace period is 0 days.

When enabled, users whose email was flagged as invalid by an admin cannot submit the same address again and must use a different one. When disabled (default), they may re-enter the same address if they believe the flag was a mistake.

Encrypted repository backups

Managed servers can back up this platform, its wikis, and the deployed website to a private GitHub or Forgejo repository. The server administrator configures bananawiki backups and keeps the recovery key offline. Scheduling is optional and starts disabled. Setup and restore instructions are in docs/backups.md in the application source. Telegram backup delivery is retired. Google Drive remains available below.

Google Drive Backup

Automated nightly backups of the hosting platform to Google Drive. Backups include the platform database, configuration files, and all instance data. Old backups are automatically deleted based on the retention policy.

Upload a Google Cloud service account JSON key file. Create one in the Google Cloud Console, then share your Google Drive backup folder with the service account email.
