Container media verification

Build both images from the repository root:
  docker build -f Dockerfile -t bananawiki-media .
  docker build -f Dockerfile.tenant -t bananawiki-tenant-media .
Behind an HTTPS-intercepting build proxy, pass its CA bundle with
  --secret id=proxy_ca,src=/path/to/combined-ca-bundle.pem
TLS and signature checks stay on, and the secret is not stored in any layer.

ACL library and GNU utilities (replace IMAGE with either image):
  docker run --rm --read-only --user 23456:23456 --network none \
    --tmpfs /tmp:rw,nosuid,nodev,size=128m --cap-drop ALL \
    --security-opt no-new-privileges --memory 384m --cpus 0.5 \
    --pids-limit 96 -i --entrypoint python IMAGE - \
    < docker/media/verify-acl.py
Checks the descriptor-based ACL calls (an ancestor replaced by a symlink,
AT_EMPTY_PATH, refused final symlinks and invalid flags), cp -a and GNU tar
round trips with modes, ACLs, symlinks, hard links and sparse files, and the
GNU timeout deadline. The legacy path-based ACL calls still follow symlinks.

FFmpeg (either image, as an arbitrary non-root UID):
  docker run --rm --read-only --user 23456:23456 --network none \
    --tmpfs /tmp:rw,noexec,nosuid,size=128m --cap-drop ALL \
    --security-opt no-new-privileges -i --entrypoint python IMAGE - \
    < docker/media/verify-ffmpeg.py
Checks the six PCM WAV sample formats and MP3 input at seven speeds from 0.5
to 2.0, parses every MP3 output frame and its duration, the stereo 48 kHz pipe
conversion the GPU server uses, both MP3 decoders, rejection of malformed
input, the compiled feature set, and the pinned source, signature and licence
files.

To check the sound itself, mount a directory owned by your host UID at
/evidence, run the FFmpeg verifier with --user <host-uid>:<host-gid> and
-e MEDIA_VERIFY_OUTPUT=/evidence, then run
  python docker/media/verify-decoded-audio.py /path/to/that/directory
with a full FFmpeg installation on the host. It decodes the 49 MP3 outputs and
checks amplitude, duration and pitch. (The image's FFmpeg cannot do this: it has
no PCM output encoder.)

FFmpeg is built from source, so OS and Python package scanners do not see it.
Add /usr/local/share/bananawiki/media/ffmpeg.cdx.json to your image inventory
and follow https://ffmpeg.org/security.html for the shipped release.

The runtime image removes APT, Perl, login and mount utilities through the
package manager and keeps the package records, Python's UUID/curses/readline
libraries, the C++/OpenMP libraries ONNX Runtime needs, GNU timeout, TLS roots
and fonts. Scanners may report advisories for those libraries that concern
utilities the image does not ship.

Also test the application in the image: read-only start as an arbitrary UID,
tenant task deadlines, TLS verification, PDF fonts and real speech synthesis.
Test the GPU speech server on the GPU machine it will run on.
