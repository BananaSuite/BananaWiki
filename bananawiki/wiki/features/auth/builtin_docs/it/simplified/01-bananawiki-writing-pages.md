# Scrivere pagine

Le pagine si scrivono in Markdown: testo semplice con pochi simboli per titoli, elenchi e link.

## Riferimento rapido

| Scrivi | Risultato |
|---|---|
| `# Titolo` | titolo grande |
| `## Sezione` | titolo di sezione |
| `**grassetto**` | testo in grassetto |
| `*corsivo*` | testo in corsivo |
| `` `codice` `` | codice in linea |
| `- voce` | elenco puntato |
| `1. voce` | elenco numerato |
| `[etichetta](url)` | link |
| `![alt](url)` | immagine |

## Una buona pagina

Dai alla pagina un titolo chiaro, rispondi alla domanda principale nelle prime righe e metti i link alle pagine correlate. Salva subito una prima versione e migliorala dopo.

## Flusso di modifica

Apri una pagina e clicca **Modifica**. Scrivi nella scheda **Scrivi**, controlla la scheda **Anteprima**, poi salva. Bozze, cronologia, allegati ed export PDF compaiono quando sono attivi e hai il permesso di usarli.
