# Für Administratoren

Die meisten Einstellungen findest du unter **Verwaltung → Website-Einstellungen**, **Verwaltung → Benutzer** und **Verwaltung → Plugins**.

## Erste Prüfungen

- Namen der Website, Zeitzone und Sprache festlegen
- entscheiden, ob die Registrierung Einladungscodes braucht
- die ersten Konten anlegen
- die Plugins einschalten, die du jetzt brauchst
- vor großen Importen ein Backup erstellen

## Konten und Berechtigungen

Rollen legen fest, was Personen tun dürfen; Einschränkungen nach Kategorie legen fest, wo. Nutze eine eigene Rolle, wenn mehrere Personen denselben besonderen Zugriff brauchen. Halte die Zahl der Eigentümer und Superuser klein.

## Integrierte Dokumentation

**Verwaltung → Dokumentation** fügt diese Anleitung zum Wiki hinzu, ausführlich oder als Kurzanleitung, auf Deutsch, Englisch oder Italienisch. Du kannst sie auch als Markdown-ZIP herunterladen, bearbeiten und die Seiten wieder importieren.

## Backups

Nutze den Export der gesamten Website oder die Backups deines Servers. Server können außerdem verschlüsselte Backups in einem privaten GitHub- oder Forgejo-Repository aufbewahren; siehe `docs/operations.md` im Quellcode. Teste eine Wiederherstellung, bevor du dich auf ein Backup verlässt.
