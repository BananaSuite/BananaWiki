# Canvas

Ein Canvas ist eine freie Fläche mit Notizen, Formen, Bildern, Videos, Code und Links zu Wiki-Seiten, die durch Pfeile verbunden sind. Canvas findest du unter **Apps → Canvas**.

## Elemente und Verbindungen

Füge Elemente über die Werkzeugleiste hinzu und verbinde sie mit Pfeilen; die Verbindungen folgen den Elementen, wenn du sie verschiebst. Mehrere Personen können denselben Canvas gleichzeitig bearbeiten. Beim Erstellen kannst du mit einer Vorlage beginnen: einer Notiz zum Anfangen, einem Flussdiagramm, einer Mindmap, einer Retrospektive oder einer SWOT-Analyse.

## Seite oder Canvas

Eine Seite passt zu Text, der von oben nach unten gelesen wird. Ein Canvas passt zu Beziehungen: Systeme, Personen, Abhängigkeiten, Schritte oder Alternativen.

## Berechtigungen

Canvas folgen denselben Regeln wie Boards: Mitglieder erstellen sie und verwalten ihre eigenen, ein neues Canvas sieht nur, wer es erstellt hat; diese Person macht es für alle Mitglieder oder Besucher sichtbar und teilt es mit Personen oder Rollen, zum Ansehen oder Bearbeiten. Redakteure bearbeiten jedes Canvas, das sie öffnen können.

## Verlauf und Export

**Verlauf** bewahrt frühere Versionen auf und stellt sie wieder her. **Exportieren** lädt den Canvas zum Import in ein anderes Wiki herunter, und **Bild herunterladen** speichert ihn als PNG oder SVG.
