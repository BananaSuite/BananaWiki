# Chat und Nachrichten

Mit dem Chat bleiben Diskussionen im Wiki. Je nach Website-Einstellungen und Plugins können Personen Direktnachrichten senden, Gruppenchats beitreten, Dateien anhängen und Unterhaltungen moderieren.

## Direktnachrichten

Direktnachrichten eignen sich für kurze Rückfragen, Bitten um eine Prüfung und Absprachen, für die sich keine eigene Seite lohnt. Wenn eine Entscheidung später wichtig wird, halte das Ergebnis auf einer Wiki-Seite fest.

## Gruppenchats

Gruppen kannst du für Teams, Klassen, Projekte oder als Support-Kanal nutzen. Administratoren können Mitgliedschaften und Moderationseinstellungen verwalten. Gruppen funktionieren am besten, wenn jede einen klaren Zweck und einen kleinen, überschaubaren Kreis von Teilnehmenden hat.

## Anhänge und Limits

Anhänge im Chat folgen den Upload-Regeln der Website. Administratoren können Größenlimits für Dateien, tägliche Kontingente, die Nachrichtenlänge und Zeitpläne für die automatische Bereinigung festlegen. Wenn der Chat für ein Konto gesperrt ist, sollte die Person den Rest des Wikis trotzdem ganz normal nutzen können.

## Bewährtes Vorgehen

Nutze den Chat für Gespräche und Seiten für dauerhaftes Wissen. Wenn eine Unterhaltung eine Regel, einen Ablauf oder eine Antwort klärt, halte das Ergebnis in der Dokumentation fest, damit es nicht im Verlauf untergeht.
