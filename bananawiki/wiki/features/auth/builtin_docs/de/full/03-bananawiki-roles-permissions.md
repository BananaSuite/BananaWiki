# Rollen und Berechtigungen

Berechtigungen legen fest, was jede Person sehen und tun kann. BananaWiki beginnt mit einfachen Rollen und lässt Administratoren alles genauer einstellen, wenn ein Team das braucht.

## Integrierte Rollen

| Rolle | Typischer Zugriff |
|---|---|
| **Benutzer** | Seiten lesen, suchen, erlaubte Werkzeuge zur Zusammenarbeit nutzen |
| **Redakteur** | Seiten und Kategorien erstellen und bearbeiten |
| **Administrator** | Konten, Einstellungen, Plugins und das Verhalten der gesamten Website verwalten |
| **Eigentümer** | Administratorzugriff, den normale Administratoren nicht ändern können |

## Eigene Rollen

Eigene Rollen verbinden eine Basisrolle mit bestimmten Berechtigungen und Regeln für Kategorien. Nutze sie, wenn eine integrierte Rolle zu weit gefasst ist, zum Beispiel **Support-Redaktion**, **Kursassistenz** oder **Externe (nur lesen)**.

## Ausnahmen für einzelne Konten

Administratoren können einzelne Berechtigungen für ein bestimmtes Konto abweichend festlegen. Das ist hilfreich für vorübergehende Ausnahmen; wenn mehrere Personen denselben Zugriff brauchen, lassen sich eigene Rollen aber leichter pflegen.

## Einschränkungen nach Kategorie

Rollenberechtigungen beantworten die Frage *Was darf diese Person tun?* Kategorieeinschränkungen beantworten die Frage *Wo darf sie es tun?* Wenn du beides kombinierst, kann eine Person einen Bereich bearbeiten und einen anderen nur lesen.

## Praktische Tipps

Beginne mit der kleinsten Rolle, die ausreicht. Gib Personen eine höhere Rolle, wenn sie mehr Verantwortung übernehmen. Überprüfe regelmäßig, wer Administrator oder Eigentümer ist. Nutze für kurzfristigen Zugriff besser befristete Konten oder befristete Rollen, wenn das entsprechende Plugin aktiviert ist.
