# Chat and messages

With chat switched on, members can send direct messages and talk in groups. Messages and groups are under **Apps**.

## Direct messages

Open **Messages** and enter a user name to start a conversation. When a conversation settles something, write it down on a page so others can find it.

## Group chats

Create a group, or join one with its invite code. Group owners and moderators add and remove members and mute or ban someone. The owner also changes the invite code.

## Blocking someone

Anyone can block another member from their conversation, from a group's member list, or under **Settings → Blocked people**. What a blocked member sends you is not delivered (not even after you unblock them), they cannot start a conversation with you or add you to a group, and their messages in groups you share are hidden from you. They are not told, and nobody else sees whom you blocked. Unblock them in the same settings section.

## Attachments and limits

Administrators set the file size limit, the number of files per day, the message length and how long messages and files are kept before they are deleted automatically. Administrators can read conversations for moderation.
