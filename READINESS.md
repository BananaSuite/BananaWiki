# Readiness

Each item of the release checklist, the command that checked it and the result.
Checked on 10 and 11 October 2026 against the 1.7.0 tree (released as one
commit on top of `main`, `519ac7d`), BananaWiki 1.7.0, Python 3.14.4, Linux x86_64. The rows
marked "after the merge" were run again once the mascot (pull request #21)
was merged and the fixes for the production incident were made
(AUDIT.md, "Production incident: update onto ext4 storage"); the rows
marked "final" once more after the open-source pass (deployment-neutral
records and tests, the operator's own name and legal pages, and the

fsync becomes a no-op for the test databases only) because the shared disk is
I/O-bound. The browser checks used Playwright 1.62 with Chromium and the
crawl harnesses of the visual pass, which are not part of the repository.
Findings and their status are in [AUDIT.md](AUDIT.md); open decisions in
[BLOCKERS.md](BLOCKERS.md). Pull requests #22 (German) and #23 (the third
hardening round) were then merged from `origin/main` at `3dde316` (AUDIT.md,

the upstream merge" were run again on that tree, the browser crawls in
German as well. The owner then made XFS optional (AUDIT.md, "Owner
decision: XFS is optional"); the rows marked "after XFS became optional"
were run again once that change and the fixes of its review were made.

polish) were then merged from `origin/main` at `519ac7d`, and the owner made
the mascot's pixel-art banana every icon (AUDIT.md, "Upstream merge: German

rows without those marks (clean install, production start, dependency
