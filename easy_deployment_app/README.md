# BananaWiki Easy Deployment App

The Easy Deployment App is a portable desktop launcher for one standalone
BananaWiki instance. It is designed for non-technical users who need a local
server for work without installing Python, nginx, systemd, or the hosting
platform.

## User Experience

1. User opens the executable.
2. The app creates a `bananawiki` folder next to the executable.
3. The app checks internet connectivity and whether the computer is connected to a local network.
4. The app shows whether previous BananaWiki data was found.
5. User chooses whether other devices on the local network can connect.
6. User clicks **Start**.
7. The app starts a local BananaWiki server and shows the address to visit.
   In classroom mode it shows both the host-computer address and the LAN
   address for student devices, plus a QR code.
8. User clicks **Stop** when finished.

Keeping the `bananawiki` folder keeps pages, uploads, settings, accounts,
logs, the SQLite database, and the Flask secret key used for browser sessions.

## Runtime Model

The GUI starts a subprocess in `--server-child` mode. That child imports the
normal BananaWiki Flask app and serves it with Waitress when available. The app
sets `BW_*` environment variables so all mutable data lives in:

```text
bananawiki/
  instance/bananawiki.db
  instance/.secret_key
  uploads/
  attachments/
  chat_attachments/
  kanban_attachments/
  custom_page_files/
  favicons/
  tts/
  logs/bananawiki.log
```

This launches the standalone wiki only. It does not launch the multi-tenant
hosting platform.

## Offline Labs

No internet connection is required for the wiki itself. If students need to
connect from other devices, all devices must be on the same local network, such
as a classroom router, travel router, or phone hotspot. The operating system may
ask for firewall permission the first time network sharing is used.

In classroom network mode, students can scan the QR code or type the shown LAN
address manually.

## Building Portable Executables

Use PyInstaller on each target platform. PyInstaller does not reliably
cross-compile GUI apps, so build Windows on Windows, Linux on Linux, and macOS
arm64 on Apple Silicon macOS.

```bash
python -m pip install -r requirements.txt pyinstaller
python scripts/build_easy_deployment.py
```

Expected build targets:

- Windows x86/x64: `BananaWikiEasyDeployment.exe`
- Linux x86/x64: `BananaWikiEasyDeployment-linux-x86_64.tar.gz`
- macOS arm64: `BananaWikiEasyDeployment-macos-arm64.zip`, containing
  `BananaWiki Easy Deployment.app`

Distribute the final artifact without an installer. On first run it
creates the user data folder beside itself. For Linux and macOS, distribute the
archive generated by `scripts/build_easy_deployment.py`; uploading the raw
binary or raw `.app` folder through artifact hosting can strip executable
permission bits and produce a download that is no longer runnable.

## Notes

- Computer-only mode binds to `127.0.0.1`.
- Classroom network mode binds to `0.0.0.0` and shows the LAN address.
- Some managed school networks block device-to-device access; use a dedicated
  local router/hotspot in that case.
